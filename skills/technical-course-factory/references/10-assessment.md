# 10 — Assessment

Assessment answers: “can the learner do the thing?” It is not a compliance checkbox.

## Formative assessment

Per lesson:

- Guided exercise.
- Independent exercise.
- Quiz (3–5 questions).

Per module:

- Module recap quiz or a small project.
- Review of previous mistakes.

## Summative assessment

- Capstone project.
- Final quiz.
- Portfolio piece.

Choose based on the course goal. A fundamentals course may not need a capstone; an advanced course probably does.

## Quiz design

- 3–5 questions per lesson.
- Mix:
  - Recall.
  - Prediction (“what does this print?”).
  - Debugging (“why does this fail?”).
  - Application (“which approach fits?”).
- Avoid trick questions.
- Include answers and brief explanations.
- If the platform supports auto-grading, mark the correct option and feedback.

## Exercise grading

For open-ended exercises, provide:

- Acceptance criteria.
- Rubric with 4 levels.
- Example of “good enough”.
- Optional solution.

For code exercises:

- Input/output examples.
- Edge cases.
- Tests or a test description.
- Manual review criteria if auto-grading is not possible.

## Rubric template

| Criterion | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Correctness | Fails | Partially works | Works | Works with edge cases |
| Clarity | Confusing | Understandable | Clear | Idiomatic and concise |
| Testing | None | Some | Covers main path | Covers sad paths |
| Reflection | None | Superficial | Identifies issues | Proposes improvements |

## Solutions

- Default: separate folder, not linked from the lesson.
- Optional: at the end of the lesson, collapsed if the platform supports it.
- Never put solutions in the main content by default.
- Solutions must be checked for correctness; a wrong solution is worse than none.

## Capstone

- Integrates several modules.
- Has a real context.
- Has acceptance criteria and a rubric.
- Includes failure scenarios.
- Requires documentation or a short retrospective.

## Assessment checklist

- [ ] Every lesson has a quiz or practical check.
- [ ] Exercises map to objectives.
- [ ] At least one sad path or edge case.
- [ ] Rubric for open-ended work.
- [ ] Solutions separate or clearly marked.
- [ ] Capstone has acceptance criteria.
- [ ] No assessment asks for untaught concepts.
